# Jay's Day

A private daily journal and goal planner that installs on a phone.

- Entries are stored on the phone only. Nothing is sent to a server.
- Works without signal once it has been opened once.
- Back up from **More → Backup and restore**.

## Files

- `index.html` – the whole app
- `sw.js` – offline support (bump `CACHE` when files change)
- `manifest.webmanifest`, `icons/` – install details and app icon
- `fonts/` – Bricolage Grotesque and Instrument Sans (SIL Open Font License)
